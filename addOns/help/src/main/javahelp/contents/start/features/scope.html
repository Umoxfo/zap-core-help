Scope

The Scope is the set of URLs you are testing, defined by the Contexts you have specified.

By default, nothing is in Scope.

Scope Effects

The Scope affects the following aspects of ZAP's operation:

  • What actions you can perform when in Protected Mode.
  • What is shown in the History tab.

Modes

The Scope determines certain application behavior based on the Mode ZAP is operating in:

  • Protected: Users can only perform (potentially) dangerous actions on URLs that are in Scope.
  • Standard: As in previous releases, users can perform any action.
  • ATTACK: New nodes that are in Scope are actively scanned as soon as they are discovered.

It is recommended that you define a new Context for each web application you are testing, and ensure they are set in Scope as you test each one.
